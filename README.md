# 🎬 Short-Form Video Pipeline

Полностью автоматизированный конвейер производства вертикальных видео для TikTok / Instagram Reels / YouTube Shorts с бюджетом $0.

## 📊 Интерактивная демо-страница

Откройте вкладку **"🎬 ДЕМО"** в дашборде, чтобы увидеть имитацию видео через последовательность кадров с таймингами.

### Что вы увидите:

- **2 демо-ролика** с разными темами:
  1. "Рост госдолга США" (35 сек)
  2. "Население Земли" (33 сек)

- **Интерактивный плеер** с:
  - ▶️ Автоплеем слайдшоу
  - 🎯 Индикатором текущего сегмента (ХУК / КОНТЕКСТ / ДАННЫЕ / ТВИСТ / CTA)
  - 💬 Кинетическими субтитрами (word-by-word)
  - 📊 Прогресс-баром с маркерами сегментов
  - ⏱️ Таймлайном с возможностью перемотки
  - 🔄 Кнопками Play/Pause/Restart

### Структура каждого ролика:

```
0.0–1.5с    🎯 ХУК        — Крупная цифра + обещание
1.5–8с      📖 КОНТЕКСТ   — Усиление ставки
8–25с       📊 ДАННЫЕ     — Анимированные графики
25–32с      💡 ТВИСТ      — Неожиданный вывод
32–35с      🔔 CTA        — Призыв к подписке
```

## 🚀 Быстрый старт (локально)

### 1. Установка зависимостей

```bash
# Python-пакеты
pip install edge-tts faster-whisper moviepy matplotlib plotly kaleido \
  geopandas pillow pandas pyyaml requests numpy

# Системные зависимости
# Ubuntu/Debian:
sudo apt install ffmpeg make

# macOS:
brew install ffmpeg make

# Windows (Chocolatey):
choco install ffmpeg make
```

### 2. Создание структуры проекта

```bash
mkdir -p pipeline content output data/cache
```

### 3. Копирование кода

Скопируйте все файлы из вкладки **"ЭТАП 1"** дашборда:
- `pipeline/research.py`
- `pipeline/script.py`
- `pipeline/voice.py`
- `pipeline/visuals.py`
- `pipeline/captions.py`
- `pipeline/assemble.py`
- `pipeline/compliance.py`
- `pipeline/batch.py`
- `pipeline/publish_plan.py`
- `config.yaml`
- `Makefile`
- `requirements.txt`
- `content/ideas.csv`
- `content/hooks.json`

### 4. Генерация видео

```bash
# Один ролик
make video TOPIC="Рост госдолга США"

# Батч-режим (10 роликов)
make batch N=10

# Проверка окружения
make check

# План публикаций на 14 дней
make publish-plan
```

### 5. Результат

Готовые видео появятся в папке `output/`:
- `output/Рост_госдолга_США.mp4` — мастер-файл (1080×1920, H.264, AAC)
- `output/Рост_госдолга_США.json` — sidecar метаданные с флагом `synthetic_media: true`
- `output/Рост_госдолга_США.srt` — субтитры

## 🔧 Технические детали

### Видео
- **Разрешение:** 1080×1920 (вертикальное)
- **Кодек:** H.264 (libx264)
- **Аудио:** AAC 128 kbps
- **FPS:** 30
- **Размер:** ≤ 40 MB
- **Длительность:** 22–45 сек

### Безопасная зона
- Снизу: 220px (UI TikTok)
- Справа: 120px (кнопки лайк/коммент)
- Сверху: 100px
- Слева: 60px

### Палитра
- Фон: `#0B1120` (Deep navy)
- Акцент 1: `#22D3EE` (Cyan)
- Акцент 2: `#A78BFA` (Violet)
- Текст: `#F8FAFC` (White)
- Хук: `#FBBF24` (Amber)

### Голос
- **Модель:** ru-RU-DmitryNeural
- **Скорость:** +8%
- **Движок:** edge-tts 6.1.10

### Субтитры
- **Модель:** faster-whisper tiny (CPU)
- **Тип:** word-level таймкоды
- **Стиль:** кинетические, текущее слово подсвечено
